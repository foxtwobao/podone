# 新板型模板

复制本目录为 `boards/<board-id>/` 后，按下面的清单填完再开始写功能代码。本目录不含可编译代码。

## 开工前要确认的事项

- 板型 ID。小写字母、数字和连字符，发布后不再复用，服务端按它选择 OTA 包。
- 芯片型号与 ESP-IDF 目标名，Flash 与 PSRAM 的容量和总线模式。
- 屏幕。驱动芯片、接口、分辨率、色彩格式，复位与背光引脚。
- 触摸。控制器型号、中断与复位引脚，手势是否复用共用组件。
- 音频。编解码器型号、I²S 引脚、输入输出采样率，是否有回采参考信号。
- IMU。型号、I²C 地址、轴向到屏幕坐标的映射。没有 IMU 的板子跳过姿态跟随。
- 按键。BOOT 键以外的按键及用途。
- 与 `components/podone` 的连接点。确认屏幕尺寸、色彩格式和触摸事件能否直接交给共用组件，不能的部分写在本目录。

## 目录里应有的文件

- `README.md`：硬件来源、与通用组件的差异、实板验收记录。
- `config.h`：引脚与总线参数，每个数值注明来源。
- `sdkconfig.defaults` 与分区表：按这块板的 Flash 和 PSRAM 填写。
- `main/`：板级初始化、按键处理、与共用组件的连接。

填完后在 `firmware/README.md` 的板型清单里加一行。
